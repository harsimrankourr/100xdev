ECMA SCRIPT

    - ECMA script is a scripting language specification on which java script is based. 
    - It served as the guidelines or the rules for scripting language design

Versions of ECMA script 

    ES5, ES6, ES2015, ES2017

Java  script is a scripting language that conforms to the ECMA script specifications 
Java script is the most widely known and used implementation of ECMA script 

Beyond ECMA script 

    - Java script includes additional features that are not part of the ECMA script specifications
